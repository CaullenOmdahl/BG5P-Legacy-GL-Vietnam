# BG5P Parts Interchange Research

Date: 2026-04-29

## Short Answer

It is possible to use Car-Part as one evidence source for individual used-part searches, but it is not a good source to bulk-extract a master interchange list.

Car-Part's public search says it uses Car-Part Interchange Plus and is governed by its Website User Agreement. Car-Part's recycler and product terms describe Car-Part Interchange/Hollander Interchange as licensed/proprietary data and prohibit copying substantial interchange data, extracting Hollander data, and accessing services through means not intentionally made available. Because of that, the high-confidence workflow should not scrape Car-Part or try to clone its interchange database.

The safer, higher-confidence path for this car is:

1. Use the local Subaru EPC-derived dataset as the master OEM evidence list.
2. Use OEM part numbers and Subaru applicability notes to find donor engines/years.
3. Use Car-Part manually per part category as a salvage availability and Hollander spot-check source.
4. Only mark a donor part as 95%+ confidence when the evidence chain resolves the exact part number or a documented supersession plus all option differences.

## Vehicle Scope

Target car in this repo:

- Subaru Legacy Touring Wagon GL, model code BG5P.
- Approximate model year: 1997.
- Engine: EJ20E 2.0L naturally aspirated SOHC.
- Transmission: 5-speed manual.
- Drivetrain: full-time AWD.
- Steering/market: LHD, Vietnam/general-market export.

Important source mismatch:

- The local EPC capture is for BG5/B11 wagon, EJ20E, F4WD, 08.1997-onward, but the online variant used for extraction is an AT Brighton Gold listing.
- That is still valuable for body, chassis, general BG wagon, and EJ20E evidence.
- Manual-transmission, clutch, shifter, pedal, prop shaft, differential, ECU, wiring, and some engine accessories need extra confirmation against the actual car's transmission code/frame number.


## Confidence Rule

Do not treat "looks similar", "same chassis generation", or a Car-Part result alone as 95% confidence.

Use this rule instead:

| Confidence | Required evidence |
|---|---|
| 95%+ | Exact OEM Subaru part number match or documented Subaru supersession, target BG5/EJ20E applicability, donor model/year/engine inside the same application range, and all option constraints resolved. For used assemblies, add yard confirmation of the stamped/label part number. |
| 90-94% | Strong OEM match but one open option remains, such as LHD/RHD, ABS, airbag generation, transmission code, final drive, color/trim, or production-month split. |
| Below 90% | Same-looking part, forum claim, seller claim, Car-Part category match, or engine-family assumption without OEM-number confirmation. Do not buy as an interchange claim. |

For this project, only publish advice as 95%+ if it passes the first row.

## What Fits Best From Other Years/Engines

### Highest-confidence donor pool

Use these first when the OEM part number matches:

- BG/B11 Legacy wagon parts from the 1993-1998 generation.
- EJ20E BG5 wagon parts, especially 1996-1998 facelift-era cars.
- Same BG wagon chassis parts that are not engine-specific, transmission-specific, LHD/RHD-specific, or trim-color-specific.

### Cross-engine candidates

The generated shared-engine CSV is the right starting point for cross-engine fitment. It contains rows where the local EPC text explicitly mentions EJ20E and another engine. In this dataset the shared-engine signals are:

- EJ18E + EJ20E + EJ25D: 209 part rows.
- EJ20E + EJ25D: 85 part rows.
- EJ18E + EJ20E: 7 part rows.

These are candidates for high-confidence interchange only inside the same BG/B11 context and only when the donor part number or stamped part number matches.

Likely-good cross-engine areas, with OEM-number confirmation:

- Many general engine fasteners, plugs, seals, bearings, and brackets.
- Some starter and alternator parts.
- Some air cleaner, air intake, fuel piping, fuel tank, cooling, oil pan, and engine mounting/cooling parts.
- Some manual-transmission hardware where the note is broad and the transmission code matches.

### Chassis/body/interior candidates

These are often better donor targets than engine parts:

- Doors, glass, hinges, handles, regulators, latches, wagon rear hatch components.
- Steering column/shaft/gear parts when LHD/RHD and airbag generation match.
- Suspension arms, knuckles, hubs, bearings, brake brackets, and calipers when ABS, rotor size, axle spline, and AWD setup match.
- HVAC housings, blower parts, and A/C components when LHD/RHD and refrigerant-era fittings match.
- Interior trim and seats when color/trim, wagon body, belt/airbag generation, and side match.

### Low-confidence or no-buy without deeper proof

Treat these as below 95% until proven by exact part number, supersession, and physical checks:

- EJ20D/EJ20H/EJ20R donor engine internals, heads, intake, exhaust, turbo, ECU, and harness parts.
- USDM EJ22 engine-specific parts.
- Automatic-transmission parts for this manual car.
- Rear differential, prop shaft, axles, transmission, and clutch parts without final-drive/transmission-code confirmation.
- RHD-specific dash, steering, pedal, HVAC, harness, wiper, and cable parts.
- Facelift-sensitive lamps, grille, bumper, airbag, cluster, and trim parts without year/month and connector checks.

## How To Use Car-Part Without Lowering Confidence

Use Car-Part one part category at a time:

1. Search the closest available US/Canada listing, usually `1997 Subaru Legacy`, wagon where the UI permits it.
2. Record the part category, year range, donor model labels, yard stock number, interchange number if shown, and listing notes.
3. Call or message the yard and ask for the stamped/label OEM number, donor VIN, engine, transmission, body style, side, ABS/airbag notes, and photos of connectors/mounts.
4. Match that evidence against `docs/bg5p-oem-parts-master.csv` and the Subaru EPC/PartSouq part page.
5. Mark the part 95%+ only when the OEM number or supersession and option constraints agree.

Car-Part is useful for availability and a professional salvage interchange sanity check. It should not be the sole source of truth for this imported BG5P because US listings often map to USDM Legacy/Outback donor pools rather than the EJ20E general-market BG5P.

## Source Hierarchy For Fitment Advice

Use this order:

1. Exact target frame/VIN in Subaru EPC or PartSouq.
2. Exact OEM part number and Subaru supersession chain.
3. Same OEM number appearing under another BG/B11 donor engine/year.
4. Car-Part/Hollander manual lookup for the same part category.
5. Yard photo/stamping confirmation.
6. Forum/seller claims only as leads, not proof.

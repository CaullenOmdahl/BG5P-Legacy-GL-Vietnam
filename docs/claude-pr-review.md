# Opt-in Claude PR review

This repository's source configuration is **inactive**. No credential, variable, app installation, security setting or paid commitment was created. The current draft PR intentionally does not trigger it. Existing Claude app presence alone does not activate an Actions workflow.

After an explicitly authorized activation decision, a maintainer must provide a repository-scoped `ANTHROPIC_API_KEY` Actions secret, confirm the explicitly selected `claude-sonnet-4-6` model and set `BG5_CLAUDE_AUTO_REVIEW_ENABLED=true`. Adding credentials, enabling usage (up to $5 per run), or altering access requires separate action-time approval. The workflow must first be accepted onto the trusted base branch; this PR does not authorize merging it. Do not enable another automatic Claude integration in parallel. The current final-head audit remains owned by the parent and must not be duplicated by activating this workflow.

Only same-repository, non-draft PR events from human authors with owner/member/collaborator association are eligible. Forks, bots and comments cannot trigger it. The job has contents/PR/Actions **read** permissions only, with no OIDC, write token, PAT or checkout. It retrieves a frozen diff through the GitHub API; it never installs or executes PR code. Missing credentials skip model execution. Binary, incomplete or >120,000-character diffs skip review rather than silently claim coverage. Changed heads and closed PRs skip. Existing exact-head Claude reviews/artifacts suppress duplicates; PR concurrency avoids overlapping executions. Expired artifacts, failed runs and owner-requested reruns may require a new explicit review decision. There is no comment-trigger loop, bot commit loop or automatic fallback reviewer.

The official Claude action is pinned to an immutable commit. The model sees a static untrusted diff, with built-in tools disabled, all MCP tools denied, empty strict MCP configuration, no settings sources, safe mode, one turn and a $5 budget. It receives no checkout, PR skills, hooks or plugins. Credential inputs are restricted to the official action and a presence-only check. The action gets only the ephemeral read-scoped GitHub token; no repository-write credential is exposed to the model. Full execution logs and automatic public comments are disabled. Only a validated nonempty structured report is saved as an exact-head artifact for 14 days. Read that artifact; a green Actions job is neither a clean finding disposition nor approval.

This is a bounded automatic diff assessment, not an independent-provider implementation-review gate certificate: missing source context, oversized changes, unresolved prior findings and live validation still need the single selected reviewer and owner. Follow the installed one-review-route policy: retain unchanged evidence, review behavioral deltas, do not trigger remote review after a completed independent local review simply to duplicate it. Repository automation cannot read the machine's private cooldown ledger, so the maintainer must coordinate automatic activation with that selected route. No branch protection or required check was added.

# Opt-in Claude PR review

This repository's source configuration is **inactive**. No credential, activation variable, app installation, security setting or paid commitment was created. The current draft PR intentionally does not trigger it. Existing Claude app presence alone does not activate this workflow.

After an explicitly authorized activation decision, a maintainer must provide a repository-scoped `ANTHROPIC_API_KEY` Actions secret, confirm the selected `claude-sonnet-4-6` model/runtime support, and set `BG5_CLAUDE_AUTO_REVIEW_ENABLED=true`. Adding credentials or enabling usage (up to $5 per run) requires separate action-time approval. The workflow and `.github/claude-runtime/` files must first be accepted onto the trusted base branch; this PR does not authorize merging them. Do not activate another automatic Claude integration in parallel. Parent owns the current final-head review; activating this workflow must not duplicate that selected route.

Only same-repository, non-draft PR events from human authors with owner/member/collaborator association are eligible. Forks, bots and comments cannot trigger it. Contents/PR/Actions permissions are **read** only, with no OIDC, write token, PAT or checkout. The controller obtains comparison metadata using immutable full base/head commit IDs and the diff using immutable merge-base/head IDs. It checks API caps, file-header/line totals and post-acquisition PR head/base/eligibility. A transient A→B→A update cannot substitute B content because mutable PR source endpoints are never used. Empty/capped (300-file), binary, incomplete or >120,000-character comparisons skip rather than claim coverage. Exact-head existing Claude reviews/artifacts and PR concurrency suppress duplicates. Failed runs, expired artifacts or explicit reruns may need a new owner review decision. No comment or bot-commit loop, automatic provider fallback, merge or deployment is configured.

The pinned GitHub action's string parser was independently shown to lose `--tools ""` and `--setting-sources ""`. Therefore the model step now uses the **official Agent SDK 0.3.295 directly with documented typed isolation options**, avoiding that parser entirely. It retrieves `package.json`, its integrity-bearing lockfile and `options.mjs` from the immutable trusted base, installs with `npm ci --ignore-scripts` in runner temp without model credentials, and verifies the exact SDK source hash before importing it. It never installs or executes PR code. Runtime dependencies, including native platform packages, are locked; there is no PR-supplied npm configuration, hook or script.

`buildReviewOptions()` sets `tools: []`, `settingSources: []`, `mcpServers: {}`, `strictMcpConfig: true`, `disallowedTools: ['mcp__*']`, plan permissions, safe mode and no session persistence. It uses one turn and a $5 budget. The documented SDK empty arrays produce exactly one `--tools=` and one `--setting-sources=` in the actual CLI argv, with no default settings-source fallback. The child environment **replaces** inheritance and contains only the Anthropic credential and PATH; runner/GitHub credentials are not forwarded. The session runs in an empty temporary directory. No bypass-permissions flag, plugin, hook, filesystem tool, shell tool, MCP tool or source checkout is granted. PR eligibility is rechecked immediately before model execution after runtime setup as well. Managed host policy remains applicable; the intended runner is a fresh GitHub-hosted Ubuntu instance.

Only a validated nonempty structured report is saved as an exact-head artifact for 14 days, with base, merge-base and head provenance. No raw SDK stream, tool output, automatic public comments or approval is published. Read the artifact: a green or skipped job is neither a clean finding disposition nor independent-policy certification. Missing context, large changes, prior unresolved findings and live verification need the single selected reviewer and owner. Follow the installed one-route policy and machine cooldown state; this workflow cannot read that private ledger. No branch protection or required check was added.

Offline regression setup from the repository root (requires existing app dependencies):

```sh
python3 scripts/prepare_review_sdk_test.py
python3 scripts/test_review_config.py
node scripts/test_review_sdk_args.mjs
```

The prepare command fetches only first-party pinned source into ignored `.agent/review-test-deps/` and verifies SHA-256. The regression reproduces the former defect using the unchanged pinned action parser with only TypeScript erasure/import resolution and the same Next bundled shell-quote substitution as the coordinator. It captures the actual published locked SDK's spawn specification and throws **before any child process starts**, using a fake key. It then tests the exact committed typed options module, asserting empty tool/settings argv, empty strict MCP setup, plan/no-persistence/safe-mode flags and absence of an inherited secret sentinel. No CLI, model, provider or workflow run is invoked. These are deterministic configuration checks, not live effective-runtime acceptance; confirm runtime/model support before separately authorized activation.

The earlier independent audit's head race is repaired and tested for equal-count A→B and transient A→B→A transitions. The subsequent audit identified the action parser defect; the typed wrapper addresses it without weakening isolation. Prior independent reports have actual-read coverage caveats; retain those instead of claiming exhaustive certification. Parent owns focused changed-head review.
